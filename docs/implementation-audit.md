# Перевірка реалізованих можливостей · 24.10.2026

Переглянуто сторінки й API Next.js, worker, репозиторії PostgreSQL, клієнти
інтеграцій, службові скрипти та CI. Перевірено імпорти від точок входу,
обробники кнопок, створення подій і шлях збереження даних.

Після видалення нереалізованих подій електромережі інших видимих продуктових
заглушок, підставних робочих даних або пунктів «буде реалізовано» не знайдено.

## Що прибрано

- П’ять невикористаних SVG із початкового шаблону Next.js.
- Непідключені UI-компоненти sidebar, sheet, separator, progress, tabs і hook
  use-mobile; невикористані змінні оформлення sidebar.
- Залежності @dnd-kit/core і @dnd-kit/sortable: перетягування в апці не підключене.
- next-themes і виклик useTheme без ThemeProvider. Апка використовує постійну
  темну тему, включно зі сповіщеннями Sonner.
- Застарілий текст README про відсутність уже реалізованих інтеграцій.

## Підключені можливості

| Можливість | Реалізація |
| --- | --- |
| Вхід і вихід | Auth API → перевірка пароля, JWT і користувачі PostgreSQL |
| Телеметрія батареї | UDP-клієнт → worker → вимірювання й хвилинні агрегати → графіки/API/CSV |
| Оцінки автономності | Поточна місткість і потужність; окрема оцінка до резерву за середнім розрядом |
| Freelancehunt | HTTP-клієнт → пагінація й дедуплікація → проєкти та непрочитані розмови |
| Особисті фільтри й робота з проєктами | API → SQL-відбір, набори, нотатки, перегляд, збереження, приховування й статус |
| Події та особиста скринька | Транзакційне збереження → особисті отримувачі → прочитання, журнал і CSV |
| Telegram | Збережені доставки → worker → HTTP-клієнт, повтори, тихі години та додатковий дайджест |
| Live-оновлення | PostgreSQL NOTIFY → автентифікований WebSocket → оновлення HTTP-даних |
| Мої сайти | Спільний CRUD посилань у PostgreSQL, групи та порядок |
| Стан системи | Реальні heartbeat, свіжість вимірювань, розмір БД і доставки |
| Резервне копіювання | pg_dump, перевірка архіву, тестове відновлення й host scheduler |
| Автоматичні перевірки | TypeScript, ESLint, ізольовані PostgreSQL-тести, збірка й браузерні сценарії |

Відсутній токен, недоступна батарея або необов’язковий показник від прошивки
відображаються як відсутність даних чи явна помилка. Це обробка реальних умов,
а не підстановка вигаданих показників. Автотести використовують синтетичні
дані й окремі бази; тестові mock/simulation-ресурси не підключені до робочої апки.

## Перевірки після очищення

- Typecheck, ESLint і production build — успішно.
- 103 тести на ізольованих PostgreSQL-базах — без пропусків і помилок.
- Браузерні сценарії: вхід, графіки, CSV, підказки, особисті нотатки й статуси,
  скринька, сайти, мобільний інтерфейс, NOTIFY/WebSocket і завершення сесії.
- Docker-образи web і worker зібрано з оновленого lockfile.
